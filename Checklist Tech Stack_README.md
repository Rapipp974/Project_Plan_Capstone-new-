
# Sistem Pemesanan Warung Mercon & Chicken Meet

## Deskripsi Proyek
Sistem pemesanan berbasis web yang dikembangkan untuk membantu proses pemesanan dan pengelolaan pesanan pada UMKM Warung Mercon & Chicken Meet dengan memanfaatkan teknologi Artificial Intelligence (AI).

## Latar Belakang
Proses pemesanan pada UMKM memiliki beberapa kendala, seperti memahami catatan khusus pelanggan, pencarian produk yang kurang fleksibel, serta belum optimalnya pemanfaatan data transaksi untuk memberikan rekomendasi menu.

## Permasalahan yang Ingin Diselesaikan
Model AI yang dikembangkan bertujuan untuk membantu mengatasi beberapa permasalahan berikut:
1. Kesulitan memahami catatan pesanan pelanggan dalam bahasa sehari-hari.
2. Kesulitan menemukan produk akibat kesalahan penulisan nama menu.
3. Belum adanya rekomendasi menu berdasarkan pola pembelian pelanggan.
4. Belum optimalnya analisis data transaksi untuk mengetahui tren pembelian.

## Fitur Utama
- NLP & Order Extraction
- Smart Search
- Product Recommendation
- Data Analysis
- Integrasi IoT

## Teknologi yang Digunakan
- Frontend: React, HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: MySQL
- AI/ML: Python, Pandas, MLxtend, RapidFuzz
- IoT: ESP32 (jika digunakan)

## Tujuan Proyek
Membangun sistem pemesanan yang dapat membantu UMKM mengelola pesanan, mempermudah pelanggan menemukan menu, serta memanfaatkan AI untuk mendukung proses operasional.
